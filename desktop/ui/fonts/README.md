# Шрифт

В этой сборке явно используется Segoe UI Variable / Segoe UI. Локальный Inter Variable не найден.
Для подключения лицензированной копии положите `InterVariable.woff2` и соответствующий `OFL.txt` в эту папку (`desktop/ui/fonts/`). Затем добавьте @font-face в base.css и Inter Variable первым в --font в tokens.css. Файлы шрифта и лицензии не подменены заглушками.
