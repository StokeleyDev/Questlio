## Questlio 0.30.3

- Original Liquid Glass buttons, filters, switches and sidebar material.
- Fixed the Reduce motion switch showing an incorrect state.
- English and Russian interface; light and dark themes.
- Reduced transparency, reduced motion and high contrast fallbacks.
- Refraction pauses while scrolling; settings controls mount when visible.

### Windows downloads

- **Questlio-0.30.3-Setup.exe** — installs for the current user, adds a Start menu shortcut and includes an uninstaller in the application folder and Windows Installed apps.
- **Questlio-0.30.3-win-x64-portable.zip** — extract the entire archive and run Questlio.exe.
- **SHA256SUMS.txt** — checksums for both downloads.

Windows 10/11 x64, Microsoft Edge WebView2 Runtime. The .NET runtime is included; no .NET SDK is required. Exit Questlio from its tray menu before installing or uninstalling. Uninstall preserves the library, backups and preferences under `%LOCALAPPDATA%/Questlio`.

### По-русски

Оригинальный Liquid Glass добавлен к кнопкам, фильтрам, переключателям и боковой панели. Исправлено отображение состояния «Меньше движения». Setup включает деинсталлятор; после удаления программы библиотека, резервные копии и настройки сохраняются. Перед обновлением выберите «Выход» в меню значка Questlio в трее.
